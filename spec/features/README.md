# Features

One file per feature, e.g. `add-account.md`, `import-statement.md`,
`net-worth-chart.md`. Each should cover:

- What the feature does, from the user's perspective
- Inputs / outputs
- Edge cases and error states you care about
- Acceptance criteria (how you'll know it's done)

Keep features small enough that one worker agent can implement one file
in a single pass. If a feature file is getting long, split it.
